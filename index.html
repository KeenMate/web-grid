WebGrid Web Component

A feature-rich data grid built as a native web component.

Examples

  • Basic Grid - Sorting, filtering, pagination, and custom formatting
  • Editable Grid - All 7 editor types: text, number, checkbox, select, combobox, autocomplete, date
  • Context Menu - Right-click menu with dynamic labels, visibility, and disabled states
  • Row Toolbar - Floating action toolbar on row hover

Features

  • Sorting
  • Filtering
  • Pagination
  • Inline Editing
  • 7 Editor Types
  • Validation
  • Context Menu
  • Row Toolbar
  • Navigate Mode
  • Keyboard Navigation
  • Dark Mode Support
  • Zero Dependencies

Quick Start

<script type="module">
  import './src/index.js'
</script>

<web-grid id="grid"></web-grid>

<script type="module">
  const grid = document.getElementById('grid')
  grid.items = [{ id: 1, name: 'Alice' }]
  grid.columns = [
    { field: 'id', title: 'ID' },
    { field: 'name', title: 'Name', sortable: true }
  ]
</script>
