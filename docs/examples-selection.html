Selection

Multi-row and cell range selection with keyboard shortcuts

Global Copy Settings:

Row/Column Selection Only

Cell selection is disabled. Select entire rows via row numbers, or entire columns via Ctrl+Click on headers.

Click row numbers to select rows...
Row/Column Selection Controls
  • Click row number - Select single row (clears others)
  • Ctrl+Click row number - Toggle row in selection
  • Shift+Click row number - Select range from last selected
  • Click+Drag on row numbers - Select range while dragging
  • Click # (top-left) - Select all cells
  • Click column header - Select entire column
  • Ctrl+Click column header - Toggle column (non-contiguous)
  • Shift+Click column header - Select range from last clicked
  • Click sort indicator (▲/▼) - Sort by column
  • Escape - Clear selection
  • Delete - Delete selected rows
  • Ctrl+C - Copy selection to clipboard
cellSelectionMode: 'disabled'  // No cell range selection

Cell Range Selection (Click+Drag)

Click and drag on cells to select a rectangular range. Works in navigate mode or when editTrigger is not "click".

Click and drag on cells to select a range...
Cell Range Selection (Click Mode)
  • Click+Drag on cells - Select rectangular range
  • Shift+Click - Extend range to clicked cell
  • Escape - Clear selection
  • Delete - Clear all values in range
  • Ctrl+C - Copy to clipboard (Excel-compatible TSV)
Mode presets: The mode property is a convenience that sets multiple properties at once. Changing it will update the controls above:
  • read-only — isEditable=false, cellSelectionMode=click
  • excel — isEditable=true, editTrigger=navigate, cellSelectionMode=click
  • input-matrix — isEditable=true, editTrigger=always, cellSelectionMode=shift (cells are always editing, so shift+drag is needed to select)
cellSelectionMode: 'click'  // Default
shouldCopyWithHeaders: false  // Include headers when copying

Cell Range Selection (Shift+Drag)

Use Shift+Click and drag to select cell ranges. This mode works with editTrigger="click" to avoid conflicts.

Hold Shift and drag to select cells...
Cell Range Selection (Shift Mode)
  • Click on cell - Enters edit mode (editTrigger="click")
  • Shift+Click+Drag - Select rectangular range
  • Shift+Click twice - Select range from first to second cell
  • Escape - Clear selection
  • Delete - Clear all values in range
  • Ctrl+C - Copy to clipboard (Excel-compatible TSV)
editTrigger: 'click'
cellSelectionMode: 'shift'  // Avoids conflict

Range Shortcuts (Works with Both)

Range shortcuts work with both row selection and cell range selection. The context automatically adapts.

Try selecting rows or cell ranges and using shortcuts...
Range Shortcuts Example
  • Ctrl+C - Copy selected rows OR cells to clipboard
  • Delete - Delete selected rows OR clear selected cells
  • Ctrl+Alt+E - Export selected rows OR cells
  • Ctrl+Alt+S - Sum values in selected cells (cell range only)
grid.rangeShortcuts = [{
    key: 'Delete',
    id: 'delete-or-clear',
    label: 'Delete rows or clear cells',
    action: ({ rows, cells, cellRange }) => {
        if (cellRange) {
            // Cell range mode - clear values
            cells.forEach(({ row, field }) => {
                row[field] = null
            })
        } else {
            // Row selection mode - delete rows
            for (const idx of rowIndices.reverse()) {
                grid.items.splice(idx, 1)
            }
        }
    }
}]

Row Focus (Master/Detail Pattern)

Click any data cell to focus its row. The onrowfocus callback fires with the focused row's data — perfect for master/detail layouts. Row number clicks do not trigger focus (they handle row selection). Clicking outside the grid clears focus.

Click a cell to see row details
No row focused
Row Focus API
  • Click cell — Focuses that row, fires onrowfocus
  • Click row number — Selects row (does NOT focus)
  • Click outside — Clears row focus
  • grid.focusedRowIndex — Get/set focused row programmatically
grid.onrowfocus = ({ rowIndex, row, previousRowIndex }) => {
    detailPanel.innerHTML = renderDetail(row)
    console.log(`Row ${rowIndex} focused (was: ${previousRowIndex})`)
}

// Programmatic control
grid.focusedRowIndex = 3    // Focus row 3
grid.focusedRowIndex = null // Clear focus

API Reference

Row Selection API

selectedRows Array of selected row indices (read-only, sorted ascending)
selectRow(idx, mode) Select a row. Mode: 'replace', 'toggle', or 'range'
clearSelection() Clear all selected rows
getSelectedRowsData() Get the data objects for selected rows

Cell Range Selection API

cellSelectionMode Selection mode: 'disabled', 'click' (default), or 'shift'
selectedCellRange Current cell range (read-only), null if none
selectCellRange(range) Select a cell range programmatically
clearCellSelection() Clear cell range selection
getSelectedCells() Get array of {row, rowIndex, colIndex, field, value} objects
oncellselectionchange Event fired when cell selection changes

Row Focus API

focusedRowIndex Get/set the focused row index (null if none)
onrowfocus Callback fired when focused row changes: { rowIndex, row, previousRowIndex }

Range Shortcuts (Works with Both)

rangeShortcuts Array of shortcuts that operate on selected rows or cells
RangeShortcutContext Context passed to shortcuts: { rows, rowIndices, cells?, cellRange? }
