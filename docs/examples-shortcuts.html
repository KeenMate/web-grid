⌨️ Keyboard Shortcuts

Grid-level keyboard shortcuts for row operations with help overlay

Row Keyboard Shortcuts

Click on any cell to focus it (navigate mode), then use the keyboard shortcuts below. Press F2 or Enter to edit. Hover over the ⓘ icon to see available shortcuts.

Available Shortcuts

Delete Delete row
Ctrl+D Duplicate row
Ctrl+Up Move row up
Ctrl+Down Move row down
F2 Edit cell
Ctrl+E Export row

Configuration

// Enable navigate mode for cell focus
grid.isEditable = true
grid.editTrigger = 'navigate'

grid.rowShortcuts = [
  {
    key: 'Delete',
    id: 'delete',
    label: 'Delete row',
    action: (ctx) => {
      items.splice(ctx.rowIndex, 1)
      grid.items = [...items]
    }
  },
  {
    key: 'Ctrl+D',
    id: 'duplicate',
    label: 'Duplicate row',
    action: (ctx) => {
      const copy = { ...ctx.row, id: nextId++ }
      items.splice(ctx.rowIndex + 1, 0, copy)
      grid.items = [...items]
    }
  }
]

// Show help icon
grid.isShortcutsHelpVisible = true

API Reference

Grid Properties

rowShortcutsArray of shortcut definitions
showShortcutsHelpShow info icon (default: false)
shortcutsHelpPosition'top-right' | 'top-left'
shortcutsHelpContentCallbackCustom HTML for overlay

RowShortcut Properties

keyKey combo (e.g., "Delete", "Ctrl+D", "F2")
idUnique identifier
labelDisplay label for help overlay
actionCallback receiving ShortcutContext
disabledBoolean or callback (optional)

ShortcutContext

The context object passed to action callbacks:

rowThe row data object
rowIndexIndex of the focused row
colIndexIndex of the focused column
columnThe column definition
cellValueValue of the focused cell

Key Format

Supported modifier keys:

  • Ctrl+ or Control+
  • Shift+
  • Alt+
  • Meta+ or Cmd+

Examples: Delete, F2, Ctrl+D, Shift+Enter
