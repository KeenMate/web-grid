Custom Styling Examples

Dynamic cell and row styling based on data values

Rainbow Salary + Inactive Rows

Demonstrates cellClassCallback for value-based cell styling and rowClassCallback for row-level styling.

  • Salary column: Rainbow gradient from red (low) through yellow/green to purple (high)
  • Inactive rows: Grayed out with reduced opacity

Table Border Only (No Double Border)

When a grid with pagination is inside a card, you get a double border effect. Use tableBorderOnly to place the border only around the table, letting pagination float outside.

Default (double border)

tableBorderOnly={true}

// Default - border wraps everything including pagination
<web-grid ...></web-grid>

// Table border only - pagination floats outside the border
<web-grid tableBorderOnly ...></web-grid>

How It Works

1. cellClassCallback (Column-level)

Returns a CSS class based on cell value and row data:

{
    field: 'salary',
    cellClassCallback: (value, row) => {
        if (value < 65000) return 'salary-1'
        if (value < 72000) return 'salary-2'
        // ... more ranges
        return 'salary-7'
    }
}

2. rowClassCallback (Grid-level)

Returns a CSS class for the entire row:

grid.rowClassCallback = (row, index) => {
    if (row.status === 'Inactive') return 'row-inactive'
    return null
}

3. customStylesCallback (Required for Shadow DOM)

Injects CSS into the shadow root:

grid.customStylesCallback = () => `
    .salary-1 { background: #fee2e2 !important; }
    .salary-2 { background: #ffedd5 !important; }
    .row-inactive { opacity: 0.5; }
`
