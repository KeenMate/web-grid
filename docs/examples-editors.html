Custom Editor

Use editor: "custom" with cellEditCallback for dialog-based editing.

{
    field: 'notes',
    editor: 'custom',
    cellEditCallback: (context) => {
        // context contains:
        // - value: current cell value
        // - row: full row data
        // - rowIndex: row index
        // - field: column field name
        // - commit(newValue): save and close
        // - cancel(): discard and close

        const newValue = prompt('Edit:', context.value)
        if (newValue !== null) {
            context.commit(newValue)
        } else {
            context.cancel()
        }
    }
}
Triggers

Custom editor opens on: F2, Space, double-click, or navigate mode entry

Context Menu

Set contextMenu array on the grid element.

grid.contextMenu = [
    {
        id: 'copy',
        label: 'Copy value',
        icon: '📋',
        onclick: (ctx) => {
            navigator.clipboard.writeText(ctx.cellValue)
        }
    },
    {
        id: 'delete',
        label: 'Delete row',
        icon: '🗑️',
        danger: true,
        dividerBefore: true,
        disabled: (ctx) => ctx.row.protected,
        onclick: (ctx) => { ... }
    }
]

Context Menu Item Properties

Static Properties

  • id - Unique identifier (required)
  • label - Display text (string or callback)
  • icon - Emoji or HTML for icon
  • danger - Red styling for destructive actions
  • dividerBefore - Add separator line above

Dynamic Properties

  • visible - Show/hide (boolean or callback)
  • disabled - Disable item (boolean or callback)
  • onclick - Click handler with context

Context Object

  • value - Cell value
  • row - Full row data
  • rowIndex - Row index
  • field - Column field name
  • colIndex - Column index
