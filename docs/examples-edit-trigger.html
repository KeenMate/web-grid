Edit Trigger Examples

Testing different edit trigger modes

Edit Trigger: Click

Single click on a cell to start editing. Click another cell to immediately switch to editing that cell.

Test Scenarios
  • Click mode: Click Alice → edit mode. Click Bob → should immediately edit Bob (no double-click)
  • DblClick mode: Double-click to edit. Single click just focuses.
  • Navigate mode: Arrow keys to navigate, type to start editing, Enter/F2 to edit.
Edit Start Selection
  • mousePosition: Cursor placed where you clicked (default)
  • selectAll: All text selected
  • cursorAtEnd: Cursor at end of text
  • cursorAtStart: Cursor at beginning of text

Column-level editable vs Grid-level editable

When grid.isEditable = true, all columns are editable by default unless column.isEditable = false.

Column column.isEditable column.editor Result
ID false - NOT editable
Name (not set) 'text' Editable (has editor)
Email (not set) 'text' Editable (has editor)
Salary (not set) 'number' Editable (has editor)
Status (not set) 'select' Editable (has editor)
