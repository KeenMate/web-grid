GM02: Edit Triggers

Control how users enter edit mode with editTrigger.

dblclick — Double-click to enter edit mode. Default trigger. Prevents accidental edits.

GM03: Edit Start Selection

Control cursor position when entering edit mode with editStartSelection.

selectAll — All text is selected when entering edit mode. Typing replaces the entire value. This is the default.

GM04: Dropdown Behavior

Configure dropdown toggle visibility and auto-open behavior for select, combobox, and autocomplete editors.

dropdownToggleVisibility
always shows the dropdown arrow even when not editing. on-focus shows it only when the cell is focused.

API Reference

Property Type Default Description
mode 'read-only' | 'excel' | 'input-matrix' 'excel' Sets sensible defaults for common use cases
editTrigger 'click' | 'dblclick' | 'navigate' | 'always' | 'button' 'dblclick' How users enter edit mode. Per-column override available.
editStartSelection 'selectAll' | 'mousePosition' | 'cursorAtStart' | 'cursorAtEnd' 'selectAll' Cursor/selection when entering edit. Per-column via editorOptions.
dropdownToggleVisibility 'always' | 'on-focus' 'always' When to show dropdown toggle arrow. Grid-level and per-column.
shouldShowDropdownOnFocus boolean true Auto-open dropdown when cell receives focus.
shouldOpenDropdownOnEnter boolean false Enter opens dropdown (true) or moves to next row (false).
cellSelectionMode 'disabled' | 'click' | 'shift' 'click' How to select cell ranges.
isEditable boolean true Enable/disable editing globally. Column isEditable overrides.
