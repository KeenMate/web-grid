🛠️ Row Toolbar

Floating toolbar with row actions - add, delete, duplicate, and reorder

Controls

Horizontal Align only applies when toolbar appears above the row (top position).

Tasks List with Row Actions

Hover over a row to see the toolbar with Add, Delete, Duplicate, Move Up, Move Down buttons.

Predefined Toolbar Items

Use these string shortcuts for common row actions:

ID Icon Action
add+Add new row below
delete−Delete current row (danger style)
duplicate⧉Duplicate current row
moveUp↑Move row up
moveDown↓Move row down

Usage

// Enable toolbar with predefined actions
grid.showRowToolbar = true
grid.rowToolbar = ['add', 'delete', 'duplicate', 'moveUp', 'moveDown']
grid.toolbarTrigger = 'hover' // or 'click', 'button'

// Handle toolbar clicks
grid.ontoolbarclick = (detail) => {
    const { item, rowIndex, row } = detail
    console.log('Clicked:', item.id, 'on row', rowIndex)

    switch (item.id) {
        case 'add':
            // Add new row after current
            break
        case 'delete':
            // Delete current row
            break
        // ...
    }
}

Custom Toolbar Items

Define custom items with icons, labels, and handlers:

grid.rowToolbar = [
    'add',  // Predefined shorthand
    'delete',
    {
        id: 'archive',
        icon: '📦',
        title: 'Archive row',
        onclick: ({ row, rowIndex }) => {
            console.log('Archiving row:', row)
        }
    },
    {
        id: 'lock',
        icon: '🔒',
        title: 'Lock row',
        disabled: (row) => row.locked,  // Dynamic disabled state
        onclick: ({ row }) => {
            row.locked = true
        }
    }
]

Multi-Row Toolbar with Groups

Use row and group properties to organize toolbar buttons into multiple rows and groups:

// Row 1: Move actions (group 1) | CRUD actions (group 2)
// Row 2: Custom actions with labels
grid.rowToolbar = [
    { id: 'moveUp', type: 'moveUp', icon: '↑', title: 'Move up', row: 1, group: 1 },
    { id: 'moveDown', type: 'moveDown', icon: '↓', title: 'Move down', row: 1, group: 1 },
    { id: 'add', type: 'add', icon: '+', title: 'Add', row: 1, group: 2 },
    { id: 'duplicate', type: 'duplicate', icon: '⧉', title: 'Duplicate', row: 1, group: 2 },
    { id: 'delete', type: 'delete', icon: '−', title: 'Delete', danger: true, row: 1, group: 2 },

    { id: 'export', icon: '📤', title: 'Export row', row: 2, group: 1 },
    { id: 'preview', icon: '👁', title: 'Preview', label: 'View', row: 2, group: 1 },
    { id: 'archive', icon: '📦', title: 'Archive', row: 2, group: 2 }
]
