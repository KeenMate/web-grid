🛠️ Row Toolbar

Floating toolbar with row actions, rich tooltips, and keyboard shortcuts

Controls

Horizontal Align only applies when toolbar appears above the row (top position).

Tasks List with Row Actions

Hover over a row to see the toolbar. Press D to duplicate, Delete to delete, or ↑/↓ to move.

Predefined Toolbar Items

Use these string shortcuts for common row actions:

ID Icon Action
add+Add new row below
delete−Delete current row (danger style)
duplicate⧉Duplicate current row
moveUp↑Move row up
moveDown↓Move row down

Usage

// Enable toolbar with predefined actions
grid.isRowToolbarVisible = true
grid.rowToolbar = ['add', 'delete', 'duplicate', 'moveUp', 'moveDown']
grid.toolbarTrigger = 'hover' // or 'click', 'button'

// Handle toolbar clicks
grid.ontoolbarclick = (detail) => {
    const { item, rowIndex, row } = detail
    console.log('Clicked:', item.id, 'on row', rowIndex)

    switch (item.id) {
        case 'add':
            // Add new row after current
            break
        case 'delete':
            // Delete current row
            break
        // ...
    }
}

Custom Toolbar Items

Define custom items with icons, labels, and handlers:

grid.rowToolbar = [
    'add',  // Predefined shorthand
    'delete',
    {
        id: 'archive',
        icon: '📦',
        title: 'Archive row',
        onclick: ({ row, rowIndex }) => {
            console.log('Archiving row:', row)
        }
    },
    {
        id: 'lock',
        icon: '🔒',
        title: 'Lock row',
        disabled: (row) => row.locked,  // Dynamic disabled state
        onclick: ({ row }) => {
            row.locked = true
        }
    }
]

Rich Tooltips

Toolbar buttons support rich tooltips with title, description, and keyboard shortcut. Hover over a button to see it in action!

// Static tooltip with description
grid.rowToolbar = [
    {
        id: 'duplicate',
        icon: '⧉',
        title: 'Duplicate',
        tooltip: {
            description: 'Create a copy of this task',
            shortcut: 'D'  // Optional - auto-detected from rowShortcuts
        }
    }
]

// Dynamic tooltip with callback
grid.rowToolbar = [
    {
        id: 'info',
        icon: 'ℹ',
        title: 'Info',
        tooltipCallback: (row, rowIndex) => {
            return `<strong>Task #${row.id}</strong>
                    <div>Priority: ${row.priority}</div>
                    <div>Assigned to: ${row.assignee}</div>`
        }
    }
]

Note: When toolbar items have matching rowShortcuts (same id), the keyboard shortcut is automatically shown in the tooltip.

Keyboard Shortcuts on Hover

When the toolbar is visible (hovering over a row), keyboard shortcuts work on that row - no cell focus required!

// Define shortcuts that work when toolbar is visible
grid.rowShortcuts = [
    {
        key: 'd',
        id: 'duplicate',
        label: 'Duplicate row',
        action: (ctx) => {
            // ctx.row, ctx.rowIndex available
            duplicateRow(ctx.rowIndex)
        }
    },
    {
        key: 'Delete',
        id: 'delete',
        label: 'Delete row',
        action: (ctx) => deleteRow(ctx.rowIndex)
    },
    {
        key: 'ArrowUp',
        id: 'moveUp',
        label: 'Move up',
        action: (ctx) => moveRowUp(ctx.rowIndex)
    }
]

Multi-Row Toolbar with Groups

Use row and group properties to organize toolbar buttons into multiple rows and groups:

// Row 1: Move actions (group 1) | CRUD actions (group 2)
// Row 2: Custom actions with labels
grid.rowToolbar = [
    { id: 'moveUp', type: 'moveUp', icon: '↑', title: 'Move up', row: 1, group: 1 },
    { id: 'moveDown', type: 'moveDown', icon: '↓', title: 'Move down', row: 1, group: 1 },
    { id: 'add', type: 'add', icon: '+', title: 'Add', row: 1, group: 2 },
    { id: 'duplicate', type: 'duplicate', icon: '⧉', title: 'Duplicate', row: 1, group: 2 },
    { id: 'delete', type: 'delete', icon: '−', title: 'Delete', danger: true, row: 1, group: 2 },

    { id: 'export', icon: '📤', title: 'Export row', row: 2, group: 1 },
    { id: 'preview', icon: '👁', title: 'Preview', label: 'View', row: 2, group: 1 },
    { id: 'archive', icon: '📦', title: 'Archive', row: 2, group: 2 }
]

Inline Actions Column

Use toolbarPosition="inline" to render toolbar buttons as a fixed column instead of a floating popup. Buttons are always visible, with support for disabled and hidden callbacks per row. Keyboard shortcuts via rowShortcuts work when hovering over a row (try Delete or A).

grid.isRowToolbarVisible = true
grid.toolbarPosition = 'inline'  // Renders as column
grid.inlineActionsTitle = 'Actions'  // Optional header

grid.rowToolbar = [
    {
        id: 'edit',
        icon: '✏️',
        title: 'Edit',
        disabled: (row) => row.status === 'Done'  // Disable for completed tasks
    },
    {
        id: 'delete',
        icon: '🗑️',
        title: 'Delete',
        danger: true,
        hidden: (row) => row.priority === 'High'  // Hide for high priority tasks
    },
    {
        id: 'archive',
        icon: '📦',
        title: 'Archive'
    }
]
