Fill Handle (Autofill)

Excel-like drag-to-fill for copying values to adjacent cells

Basic Fill Demo

Click a cell to focus it, then drag the small square at the bottom-right corner to copy the value to adjacent cells.

Drag the fill handle to see the callback data...
How it works
  • Click any cell to focus it
  • A small square appears at the bottom-right corner (the fill handle)
  • Drag the handle in any direction (up, down, left, right)
  • Release to copy the source cell's value to all highlighted cells
  • Non-editable cells are automatically skipped

With Cancellation

The fillDragCallback callback can return false to cancel the fill operation. Try filling the "Status" column - it will be blocked.

Try filling different columns...
Cancellation Example
grid.fillDragCallback = (detail) => {
    // Block filling the "status" column
    if (detail.sourceCell.field === 'status') {
        alert('Cannot fill the Status column!')
        return false  // Cancel the fill
    }
}

Fill Directions

Fill works in all four directions. The direction is determined by the dominant axis of your drag.

Vertical Fill

Drag up or down to fill cells in the same column.

Horizontal Fill

Drag left or right to fill cells in the same row.

Callback Data Structure

The fillDragCallback callback receives detailed information about the fill operation:

{
    sourceCell: {
        rowIndex: 0,          // Source row index
        colIndex: 1,          // Source column index
        field: "name",        // Source field name
        value: "Alice"        // Value being copied
    },
    targetCells: [            // Array of cells to fill
        { rowIndex: 1, colIndex: 1, field: "name" },
        { rowIndex: 2, colIndex: 1, field: "name" },
        { rowIndex: 3, colIndex: 1, field: "name" }
    ],
    direction: "down"         // "up" | "down" | "left" | "right"
}

After fillDragCallback completes (unless cancelled), onrowchange is fired for each modified cell.

Configuration

editTrigger Must be "navigate" for cell focus (and fill handle) to work.
isEditable Grid must be editable for fill to work. Non-editable columns are skipped.
fillDragCallback Callback fired before fill is applied. Return false to cancel.
onrowchange Fired for each cell after fill is applied (existing callback).
