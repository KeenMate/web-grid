Context Menu

Right-click context menus for cells and column headers with dynamic items and conditional visibility

Read-Only Grid with Context Menu

Right-click any cell to see the context menu. Try "Copy Cell" to see dynamic labels based on column. Right-click the Price column to see the "Convert to Euro" option.

Editable Grid with Context Menu

Right-click to see context-aware options. Note: "Delete" is disabled for active products, "Restock" only appears for low-stock items (stock < 20).

Context Menu API

Grid Properties

contextMenuArray of menu item configurations
contextMenuXOffsetHorizontal offset from click (default: 0)
contextMenuYOffsetVertical offset from click (default: 4)
oncontextmenuopenCallback fired when context menu opens

ContextMenuItem Properties

idUnique identifier
labelDisplay text (string or function)
iconEmoji or HTML icon (string or function)
shortcutKeyboard shortcut (e.g., "C", "Delete")
disabledDisable state (boolean or function)
visibleVisibility (boolean or function)
dangerRed styling for destructive actions
dividerBeforeAdd divider line before item
onclickClick handler receiving context

Context Object

The context passed to callbacks:

rowThe row data object
rowIndexIndex of the row
colIndexIndex of the column
columnThe column definition
cellValueThe value of the clicked cell
grid.contextMenu = [
    {
        id: 'copy',
        label: (ctx) => `Copy "${ctx.column.title}"`,
        icon: '📋',
        shortcut: 'C',  // Press C to trigger
        onclick: (ctx) => {
            navigator.clipboard.writeText(
                String(ctx.cellValue)
            )
        }
    },
    {
        id: 'delete',
        label: 'Delete',
        icon: '🗑️',
        shortcut: 'Delete',
        danger: true,
        dividerBefore: true,
        disabled: (ctx) => ctx.row.isProtected,
        onclick: (ctx) => deleteRow(ctx.rowIndex)
    }
]

Menu Position Offset

Control where the context menu appears relative to the click position. Adjust the sliders and right-click to see the effect.

Header Context Menu

Right-click on column headers to access column-specific actions like sorting, freezing, and hiding. Supports predefined actions (string shortcuts) and custom items.

Right-click a column header to see the context menu...

Header Context Menu API

Grid Properties

headerContextMenuArray of predefined strings or item configs
onheadercontextmenuopenCallback fired when header menu opens

Predefined Actions

'sortAsc'Sort ascending
'sortDesc'Sort descending
'clearSort'Clear sort (auto-hides if not sorted)
'hideColumn'Remove column from grid
'freezeColumn'Freeze up to this column
'unfreezeColumn'Unfreeze this column

HeaderMenuContext

The context passed to header menu callbacks:

columnThe column definition
fieldColumn field name
columnIndexIndex of the column
sortDirection'asc' | 'desc' | null
isFrozenWhether column is frozen
grid.headerContextMenu = [
    'sortAsc',
    'sortDesc',
    'clearSort',
    { dividerBefore: true },
    'freezeColumn',
    'unfreezeColumn',
    { dividerBefore: true },
    {
        id: 'export',
        label: (ctx) => `Export ${ctx.field}`,
        icon: '📊',
        onclick: (ctx) => exportColumn(ctx.field)
    }
]
