🔒 Row Locking

Collaborative editing with row-level locking for real-time applications

External Lock API (WebSocket Simulation)

Simulate real-time locking from another user via WebSocket. Enter a row ID and click Lock/Unlock.

Employees Grid

Row locking prevents editing of locked rows. Locked rows show a 🔒 icon in the row number column. Try editing cells - locked rows will block editing.

Lock Sources

Rows can be locked from three different sources:

1. Property-based

Lock status comes directly from row data:

grid.rowLocking = {
    lockedMember: 'isLocked'  // Boolean field
}

// Or with full lock info:
grid.rowLocking = {
    lockInfoMember: 'lockInfo'  // RowLockInfo object
}

2. Callback-based

Compute lock status from row data:

grid.rowLocking = {
    isLockedCallback: (row) => row.status === 'approved',
    getLockInfoCallback: (row) => ({
        isLocked: row.status === 'approved',
        lockedBy: row.approvedBy,
        reason: 'Approved records cannot be edited'
    })
}

3. External API

Lock/unlock via JavaScript (WebSocket scenarios):

// Lock a row
grid.lockRowById(123, { lockedBy: 'John' })

// Unlock a row
grid.unlockRowById(123)

// Update row data (e.g., from server)
grid.updateRowById(123, { name: 'Updated Name' })

Configuration

// Required: Configure row identification
grid.idValueMember = 'id'
// Or use callback:
// grid.idValueCallback = (row) => row.employeeId

// Configure row locking
grid.rowLocking = {
    // Property sources
    lockedMember: 'isLocked',
    lockInfoMember: 'lockInfo',

    // Callback sources
    isLockedCallback: (row) => row.status === 'locked',
    getLockInfoCallback: (row) => ({ ... }),

    // Edit behavior
    lockedEditBehavior: 'block',  // 'block' | 'allow' | 'callback'
    canEditLockedCallback: (row, lockInfo) => {
        return lockInfo.lockedBy === currentUser
    },

    // Custom tooltip
    lockTooltipCallback: (lockInfo, row) => {
        return `Locked by ${lockInfo.lockedBy} at ${lockInfo.lockedAt}`
    }
}

// Listen for lock changes
grid.onrowlockchange = (detail) => {
    console.log('Lock changed:', detail)
}

Edit Behavior Options

Control what happens when a user tries to edit a locked row:

// Block all editing (default)
grid.rowLocking = { lockedEditBehavior: 'block' }

// Allow editing but show locked indicator
grid.rowLocking = { lockedEditBehavior: 'allow' }

// Custom callback to decide
grid.rowLocking = {
    lockedEditBehavior: 'callback',
    canEditLockedCallback: (row, lockInfo) => {
        // Allow if current user is the locker
        return lockInfo.lockedBy === currentUser
    }
}

Row Update Methods

Update row data programmatically (useful for real-time updates from server):

// Partial update - merges with existing data
grid.updateRowById(123, {
    name: 'New Name',
    salary: 75000
})

// Full replacement - replaces entire row
grid.replaceRowById(123, {
    id: 123,
    name: 'New Name',
    department: 'Engineering',
    salary: 75000,
    status: 'Active'
})

// Find row by ID
const result = grid.findRowById(123)
if (result) {
    console.log('Found row:', result.row, 'at index:', result.index)
}

API Reference

Method Description
getRowId(row)Get the unique ID for a row
findRowById(id)Find row by ID, returns { row, index } or null
isRowLocked(rowOrId)Check if a row is locked
getRowLockInfo(rowOrId)Get full lock info for a row
lockRowById(id, info)Lock a row externally
unlockRowById(id)Unlock an externally locked row
getExternalLocks()Get Map of all external locks
clearExternalLocks()Clear all external locks
updateRowById(id, data)Partial update of row data
replaceRowById(id, row)Replace entire row data
canEditCell(rowIndex, field)Check if cell can be edited (respects locks)
