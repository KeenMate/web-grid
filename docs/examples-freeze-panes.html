❄️ Freeze Panes

Excel-like frozen columns that stay visible while scrolling horizontally

Frozen Columns Demo

Scroll horizontally to see frozen columns stay in place. The row numbers and first two data columns are frozen.

How it works
  • isStickyRowNumbers: true - Row number column stays fixed on the left
  • freezeColumns: N - First N columns are frozen (after visual reorder)
  • frozen: true on Column - Mark individual columns as frozen (they move to the left)

Column-Level Frozen Property

Columns can be individually marked as frozen using the frozen: true property. Frozen columns automatically move to the left side.

Visual Reorder

In this example, the "Status" column is defined last but has frozen: true, so it appears first (after row numbers). The visual order is: Row Numbers → Status → ID → Name → Email → ...

Configuration Options

Grid-Level Properties

isRowNumbersVisible Show row number column
isStickyRowNumbers Make row numbers sticky (frozen)
freezeColumns Number of columns to freeze from left

Column-Level Properties

frozen Mark column as frozen (moves to left)
width Explicit width recommended for frozen columns
