👁 Column Visibility

Hide and show columns via context menu or API

Interactive Demo

Toggle columns with the checkboxes, the Show All / Hide All buttons, or right-click any header to use the context menu (Hide Column or the Column Visibility submenu).

Header Context Menu

Enable the predefined menu items 'columnVisibility' and 'hideColumn':

grid.headerContextMenu = [
    'sortAsc',
    'sortDesc',
    'clearSort',
    { dividerBefore: true },
    'hideColumn',        // hide this column (right-click target)
    'columnVisibility'   // submenu with a toggle for each column
]

The 'columnVisibility' submenu is generated dynamically from the current columns and shows a Show all entry plus one toggle per column.

Programmatic API

Column visibility is controlled by the isHidden flag on each column. To trigger a re-render, reassign the columns array:

// Hide a specific column
grid.columns.find(c => c.field === 'email').isHidden = true
grid.columns = [...grid.columns]  // reassign to trigger re-render

// Show everything
grid.columns.forEach(c => c.isHidden = false)
grid.columns = [...grid.columns]
Why reassign?
The grid tracks changes via its setter. Mutating a column's isHidden in place won't trigger a render — spreading the array and reassigning does.

API Reference

Property Type Description
column.isHidden boolean Hide a column while keeping it in the columns array (so visibility toggles know about it).
grid.headerContextMenu (string | object)[] Array of predefined items and custom entries. Include 'hideColumn' and/or 'columnVisibility'.
'columnVisibility' string Submenu entry — auto-generates a toggle per column plus a Show all row.
