WebGrid - Context Menu

Right-click any cell to see the context menu. Use arrow keys to navigate, Enter to select, Escape to close.

Products Grid with Context Menu

Right-click to see context-aware options. Note: "Delete" is disabled for active products. "Restock" only appears for low-stock items (<20).

Context Menu Features

  • Dynamic labels - Labels can be functions: label: (ctx) => \`Copy "${ctx.column.title}"\`
  • Conditional visibility - Show/hide based on context: visible: (ctx) => ctx.row.stock < 20
  • Conditional disabled - Disable based on context: disabled: (ctx) => ctx.row.active
  • Danger styling - Red styling for destructive actions: danger: true
  • Dividers - Add visual separation: dividerBefore: true
  • Keyboard navigation - Arrow keys, Enter, Escape

Example Code

grid.contextMenu = [
  {
    id: 'view',
    label: 'View Details',
    icon: '👁️',
    onclick: (ctx) => console.log('View:', ctx.row)
  },
  {
    id: 'copy',
    label: (ctx) => \`Copy "${ctx.column.title}"\`,
    icon: '📋',
    onclick: (ctx) => navigator.clipboard.writeText(String(ctx.cellValue))
  },
  {
    id: 'restock',
    label: 'Restock (+10)',
    icon: '📦',
    visible: (ctx) => ctx.row.stock < 20,  // Only show for low stock
    onclick: (ctx) => { /* restock logic */ }
  },
  {
    id: 'delete',
    label: 'Delete',
    icon: '🗑️',
    danger: true,
    dividerBefore: true,
    disabled: (ctx) => ctx.row.active,  // Disabled for active items
    onclick: (ctx) => { /* delete logic */ }
  }
]
